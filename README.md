# Leafnest.lk – Phase 1

Next.js 14 + Tailwind CSS. Pages: Home, Shop (search / filter / sort), Product detail.

## Run it
1. Install Node.js LTS from https://nodejs.org
2. Open this folder in VS Code, then open a terminal in it and run:
   ```
   npm install
   npm run dev
   ```
3. Open http://localhost:3000

## Things to change
- `lib/config.js` – put your real WhatsApp Business number
- `lib/products.js` – SAMPLE products (replace with your real ones, later this moves to the admin dashboard)
- Product images are placeholder illustrations (`components/PlantArt.jsx`). Real photos arrive with the dashboard in Phase 3.
